Восстанови контекст сессии. Пользователь хочет продолжить работу с того места, где остановился.

## Шаг 1 — Реестр задач

Прочитай `.claude/session/tasks.md`.

Если файл не существует — скажи:

```
Реестр задач не найден. Начни с `/task create` или `/finalize` для инициализации.
```

И завершай выполнение.

Если файл существует — разбери открытые задачи (статус `open`). Сортируй по приоритету: HIGH → MEDIUM → LOW.

## Шаг 2 — Детали открытых задач

Для каждой открытой задачи прочитай соответствующий файл `details/open-NN-slug.md`.

Из каждого файла извлеки:
- Заголовок задачи
- Секцию с описанием проблемы (первые 2-3 предложения)
- Блокеры если есть

Держи краткость — не копируй весь файл.

## Шаг 3 — Очередь

Если существует `.claude/session/queue.md` — прочитай его и покажи что запланировано следующим.

## Шаг 4 — Память

Проверь наличие файлов памяти. Если существуют — кратко упомяни релевантное:
- `.claude/memory/facts.md` — актуальные факты о проекте
- `.claude/memory/decisions/` — последние решения (смотри по дате в именах файлов)
- `.claude/memory/issues.md` — известные проблемы

Не читай всё подряд. Только если есть что-то свежее и важное.

## Шаг 5 — Вывод и следующий шаг

Сформируй вывод в формате:

```
## Контекст сессии

### Открытые задачи (X)

| # | Задача | Приоритет | Блокер |
|---|--------|-----------|--------|
| NN | {title} | HIGH | — |
| NN | {title} | MEDIUM | {blocker} |

### Детали HIGH-приоритет

**#N: {title}**
{brief problem/description — 2-3 предложения}

### Очередь
{summary из queue.md, или "Очередь пуста"}

---
С чего начнём?
```

Затем вызови `AskUserQuestion` с вариантами из открытых задач HIGH-приоритета (заголовки задач как опции). Добавь опцию "Другое" для произвольного выбора.

## Правила

- Это read-only операция — никакие файлы не создаёшь и не изменяешь
- Если `.claude/session/` не существует — не создавай его, просто сообщи пользователю запустить finalize
- Держи вывод кратким: контекст, не полное содержимое файлов
- HIGH-задачи всегда первые
- Если открытых задач нет — скажи об этом и предложи создать задачу через `/task create`
