# Privacy Policy

[English](#english) | [Русский](#русский)

## English

**cc-task-manager** is a local-only Claude Code plugin. It does not collect, transmit, or store any data outside of your machine.

### What data is stored

- Task files (markdown with YAML frontmatter) in the target project's `.claude/session/` directory
- Session context and task index in the same directory

### What data is NOT collected

- No analytics or telemetry
- No network requests to external services
- No user tracking or identification
- No cookies, tokens, or credentials

### Where data lives

All data stays on your local filesystem within the project directory. Nothing leaves your machine. The plugin has no server-side component, no database, and no external dependencies.

### Data removal

Delete the `.claude/session/` directory in your project to remove all plugin data.

## Русский

**cc-task-manager** — локальный плагин для Claude Code. Не собирает, не передаёт и не хранит данные за пределами вашей машины.

### Какие данные хранятся

- Файлы задач (markdown с YAML frontmatter) в директории `.claude/session/` целевого проекта
- Контекст сессии и индекс задач в той же директории

### Какие данные НЕ собираются

- Никакой аналитики и телеметрии
- Никаких сетевых запросов к внешним сервисам
- Никакого отслеживания или идентификации пользователей
- Никаких cookies, токенов или credentials

### Где хранятся данные

Все данные остаются в локальной файловой системе внутри директории проекта. Ничего не покидает вашу машину. У плагина нет серверной части, базы данных или внешних зависимостей.

### Удаление данных

Удалите директорию `.claude/session/` в проекте, чтобы удалить все данные плагина.
